# T-Spot Delight

Build a Premium Customer-Facing Website for T-Spot

Create a modern, premium, mobile-first customer website for T-Spot, an Asian street-food restaurant in Dhaka, Bangladesh.

The website is ONLY for customers. Do not create an admin dashboard, staff panel, login system, inventory system, POS, or management interface.

Make the website look like a real premium restaurant website, not a generic AI-generated template.

Warm, appetizing food-focused design

Clean white / off-white background

Modern typography with excellent readability

Large, high-quality food photography

Rounded cards and buttons

Soft shadows

Plenty of whitespace

Elegant micro-interactions

Smooth scrolling

Subtle entrance animations

Avoid excessive gradients

Avoid a dark theme

Avoid clutter

Avoid unnecessary animations

The design should feel young, energetic, friendly, local, and premium.

19. Important Design Rule

The final result should immediately communicate:

"This is a real, modern restaurant website that I could actually use to visit T-Spot."

Do not make it look like a generic template.

Prioritize:

Food → Menu → Reviews → Location → Call/Visit

The visitor should be able to understand what T-Spot serves and contact/find the restaurant within a few seconds.

Make the final website premium, clean, warm, appetizing, responsive, and production-ready.
